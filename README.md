# 🎓 E-Learning Management System

A Java-based **E-Learning Management System** developed as an academic project using **Java, JDBC, MySQL, DBMS, and Data Structures**.

The system provides modules for managing students, teachers, courses, quizzes, assignments, attendance, and results.

---

## 🚀 Features

### 👨‍🎓 Student Management
- Student registration and login
- View student information
- Manage student records
- Course enrollment

### 👨‍🏫 Teacher Management
- Teacher registration and login
- Teacher information management
- Course management

### 📚 Course Management
- Add courses
- View courses
- Update course information
- Delete courses

### 📝 Quiz Management
- Create quizzes
- Multiple-choice questions
- Store correct answers
- Calculate quiz results

### 📊 Result Management
- Store student results
- View results
- Manage marks

### 📅 Attendance Management
- Record attendance
- View attendance
- Manage attendance records

### 📋 Assignment Management
- Assignment-related academic management
